# Group 1: Personal Portfolio Website

A modern, responsive, and creative personal portfolio website for a student and aspiring software developer.

## Assignment Overview
- **Category:** Group 1 — Project 1 (Personal Portfolio Website)
- **Objective:** Create a personal portfolio webpage for a student with a profile, skills, projects, achievements, and contact section.
- **Tech Stack:** HTML5, CSS3 (Modern Flexbox & CSS Grid), Vanilla JavaScript (ES6+), FontAwesome Icons, Google Fonts.

## Features
1. **Hero Section:** Profile headline, dynamic typing subtitle, status pill, call-to-action buttons, key statistics, and layered portrait avatar with floating badges.
2. **About Me Section:** Academic background, degree, location, bio, and interactive education timeline.
3. **Technical Skills:** Category-based skill breakdown (Frontend, Backend & Database, Tools & Concepts) with custom visual progress bars.
4. **Projects Showcase:** Interactive project filtering (Web Apps, Full-Stack, UI/UX) with thumbnail hover effects and tech stack tags.
5. **Achievements & Honors:** Visual awards grid with hackathon accolades, scholarship honors, and certifications.
6. **Contact Section:** Responsive contact form with input validation and quick contact cards (Email, Phone, Location, Social Profiles).
7. **Dark / Light Mode:** Live theme toggle stored in browser `localStorage`.
8. **Mobile Navigation:** Responsive hamburger drawer with smooth scroll navigation.
